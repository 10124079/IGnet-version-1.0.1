# IGnet version 1.0.1

Phần mềm quản lý phòng máy Cyber Game.

## Công nghệ sử dụng
- C#
- WinForms
- SQL Server
- Crystal Report

## Chức năng
- Đăng nhập phân quyền
- Quản lý máy
- Mở / tắt máy
- Quản lý dịch vụ
- Combo giờ chơi
- Lịch sử giao dịch
- Báo cáo doanh thu

## Cách chạy
1. Restore database QLIG_NLADuc.sql
2. Mở project bằng Visual Studio
3. Chạy chương trình
